# Tinteán

The addon for World of Warcraft: Forever. It shows your guild's events and bulletins from tintean.net in the game.

## Install

Download the zip from tintean.net/download and unzip it into the game's AddOns folder:

- Windows: `World of Warcraft\_forever_\Interface\AddOns`
- Mac: `/Applications/World of Warcraft/_forever_/Interface/AddOns`

The zip contains two folders, `Tintean` and `Tintean_Inbox`. Install them both. To update (by hand), download the zip again and unzip it over the old folders.

## The desktop app

The Tinteán desktop app, for Windows and Mac, keeps the game and tintean.net in step. It also installs and updates the addon. Without the app, the addon gets the guild's news from guildmates who also run it.
